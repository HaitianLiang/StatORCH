# Reported-result provenance

The files under `results/reported/` are structured transcriptions of values in the latest supplied StatOrch manuscript / result integration materials dated 2026-09-14.

They serve two purposes:

1. make the README/frontend reproducible from machine-readable files;
2. prevent manual copying of numbers into presentation code.

They are **not** represented as raw per-unit evaluation output. When raw per-unit artifacts become public, keep those in a separate `results/raw/` or release archive and regenerate the summaries with a provenance-preserving script.

The local controlled demo under `results/demo/` is generated independently and is never used to substantiate manuscript headline numbers.
