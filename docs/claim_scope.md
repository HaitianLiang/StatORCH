# Claim scope / wording firewall

## Supported by the current reported evidence

- improved controlled 1,232-unit endpoint performance–cost trade-off relative to NearCost / HighBudget fixed sensing;
- measurement routing has independent value in A0→A1 isolation;
- checkpoint stopping is mainly a secondary cost-control mechanism;
- targeted held-out adaptation, quantification, classification and open-world suites show action specialization and nonzero oracle-headroom recovery;
- transparent HealthRules remain strong and can beat learned routing in some unseen regimes;
- external acquisition evaluation is demonstrated on REALDISP and Gas Sensor Array Drift under fixed protocols;
- StatOrch leads the evaluated REALDISP performance–cost frontier, while GSM-AFA leads Gas Drift;
- open-world evidence is directional and out-of-reference, not semantic discovery.

## Preferred terms

Use:

- `bootstrap uncertainty interval/band`;
- `out-of-reference evidence`;
- `directional unknown-mass response`;
- `regime-dependent orchestration`.

Avoid:

- universal router dominance;
- oracle-optimal stopping;
- sequentially valid confidence sequence (not established);
- calibrated unknown probability / posterior mass;
- proven semantic novel-class discovery;
- unrestricted cross-domain generalization.
