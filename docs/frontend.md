# Frontend

The dashboard is dependency-free: plain HTML/CSS/JavaScript and JSON data.

Run:

```bash
python scripts/serve_frontend.py --port 8000
```

Panels:

- Overview and headline evidence;
- evidence → diagnosis → action loop;
- controlled endpoint table;
- measurement/stopping isolation;
- module routing / oracle headroom;
- external performance-cost boundary;
- example auditable decision trajectory;
- claim boundary / reproducibility notes.

No external CDN is required.
